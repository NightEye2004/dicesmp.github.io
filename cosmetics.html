How custom items work

DiceSMP uses ItemsAdder to add the sets above without replacing vanilla Minecraft. The server sends the textures and models to your client automatically, so Java and Bedrock players see the same gear once the resource pack has loaded.

  • Older or newer client versions may render some models differently. Java 1.21.11 and the latest Bedrock version are the best match.
  • “Crate reward” marks a set that appears in a themed or vote crate. Open crates at /warp crates.
  • Sets without a crate badge are installed on the server, but no matching entry was found in the current crate files.
✦

Artwork & credits

Each set picture is the official promotional artwork from the creator’s MCModels listing. The “Art source” link on every card opens that original product page.

Item names and counts were read from the server’s ItemsAdder configuration. Variants such as draw stages, self-view models, and dyeable versions are listed individually, which is why the total reaches 854.
